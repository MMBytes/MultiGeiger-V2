## Overall verdict

**Pass — no Critical or Important findings.** This is a clean, mechanically
consistent rework. Every one of the checklist items in the task brief came
back negative for bugs: the `X_BOOL` declaration matches convention with a
safe default; the checkbox HTML's `%s`-triad argument count/order is
correct on both `#if` branches; the POST-handler's force-clear-then-persist
ordering closes the "crafted POST on a non-FeatherS3-D board" hole
completely (and is doubly defended by the no-op stub); `main.c`'s boot
sequencing loads config before seeding the fuel gauge and initializes both
well before any consumer surface can be reached; the MQTT JSON buffer-sizing
re-derivation for the 3 new fields checks out arithmetically; the HA
discovery entities are structurally valid and collision-free; and the TX
log line's format specifiers line up 1:1 with its arguments with no dead
code left over from the session's five rewrites.

**Cross-file consistency (#7), answered directly:** All four consumer
surfaces — `/status` (`http_server.c:709` `format_battery()`), MQTT
rich-state JSON (`mqtt.c:544`), HA discovery config (`mqtt_discovery.c:170-
172` via `fuel_gauge_present_`), and the per-cycle TX log line
(`transmission.c:1431`) — now gate uniformly on `fuel_gauge_present()`. The
prior review's carried-forward characterization ("3 of 4 surfaces gate on
VBUS-unreliable `fuel_gauge_present()`, one — the log line — differs by
using `fuel_gauge_ready()` + `fuel_gauge_vbus_present()`") is **no longer
accurate and should be considered resolved/moot**: this commit changed what
`fuel_gauge_present()` *means* (chip-ready AND user-ticked-the-box, not a
VCELL threshold), and it changed the TX log line to gate on that same
function too (`fuel_gauge_vbus_present()` is now purely descriptive context
inside the log string, not a gate). There is no remaining inconsistency
between the four surfaces — they are all wired to the identical predicate,
which now carries the intended "reliable, user-confirmed" meaning instead
of the old auto-detect heuristic.
